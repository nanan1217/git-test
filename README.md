# git-test

这是我在这台 Windows 笔记本上跑通的第一个 Git + GitHub SSH 仓库。

## 这台机器这次做了什么

- 排查并清除了桌面广告图标来源（鲁大师「桌面图标修复/推广」模块 + UrlBridge 广告跳转器）
- 卸载 12 个国产推广软件（鲁大师全家桶等）
- 卸载 360 全家桶，恢复 Windows Defender 实时保护
- 安装 Git 2.56.0.windows.1，配置 Ed25519 SSH 密钥并接入 GitHub

## 环境

- Windows 11 家庭中文版
- Git for Windows 2.56.0
- SSH: Ed25519
